# EBO MCP 工具参考

EBO 机器人通过 MCP 暴露了一组工具（tool），AI Agent 通过调用这些工具来控制机器人。本文列出全部工具及其参数，供开发调试和排查问题时查阅。

> 说明：不同机型（EBO MAX / EBO Air2 Plus）支持的工具数量不同，EBO MAX 支持完整能力。本文以 EBO MAX 为准。
>
> 所有工具都有一个可选参数 `lang`（BCP-47 语言标签，如 `zh-CN`、`en`），用于让机器人用对应语言播报确认语。不传则使用机器人当前配置的语言。下表不再重复列出该参数。

## 一、状态与地图查询

### `robot_status`

查询机器人当前状态。这是顺序执行任务时最常用的工具（见 [排错与最佳实践](ebo-mcp-troubleshooting.md) 的轮询章节）。

无参数。返回内容包括：

- 电量与充电状态
- 设备当前时间
- 设备任务（空闲 / 导航中 / 巡逻中等）—— 判断上一步是否完成的关键字段
- 巡逻路线、家庭成员
- 摄像头视野中检测到的人（姓名 + 在画面中的位置坐标）
- 音乐状态、当前检测人数、所在位置、屏幕亮度、IP 地址、WiFi 信号、音量

### `robot_list_locations`

列出机器人已建地图中所有可导航的地点名称。

无参数。返回可导航地点列表；如果还没建图，会返回提示。

> 调用 `robot_navigate` 前，如果不确定目标地点的准确名字，先调用本工具。 地点名必须与地图里的名字完全一致。

## 二、移动与导航

### `robot_navigate`

让机器人沿已建地图导航到指定地点。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `locationName` | string | 是 | 目标地点名，必须是地图中已存在的路点或路线名 |
| `findTarget` | string | 否 | 到达后要视觉搜索的目标名称，空字符串表示不搜索 |
| `objId` | string | 否 | 到达后自动检测的目标：家庭成员 userId，`2`=猫，`3`=狗，`4`=通用宠物；空字符串表示不检测 |
| `needReturn` | boolean | 否 | 搜索完成后是否返回起点再播报结果，默认 `false` |

### `robot_patrol`

启动全屋巡逻。巡逻路径由服务端根据地图自动注入，无需指定。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `duration` | integer | 否 | 巡逻时长（秒），`0` 表示不限时 |
| `travelTimes` | integer | 否 | 巡逻圈数，默认由服务端/设备决定 |
| `objId` | string | 否 | 巡逻中要检测的目标，同 `robot_navigate` |
| `targetName` | string | 否 | 要搜索的目标名称，空字符串表示不搜索 |

### `robot_move`

执行移动或技能动作（前进、后退、转向、旋转、八字、蛇形等）。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `moveId` | integer | 是 | 动作类型，见下表 |
| `targetDistance` | number | 否 | `moveId` 为 1/2 时是距离（米，最大 5）；为 3/4 时是角度（度）；其他为 0 |
| `angleSpeed` | integer | 否 | 转向速度：`1`=默认，`3`=小半径；默认 1 |
| `playTime` | integer | 否 | 动作执行次数，默认 1 |
| `voiceId` | integer | 否 | 音效 id，`0` 表示无音效 |

`moveId` 取值：

| 值 | 动作 | 值 | 动作 |
| --- | --- | --- | --- |
| 0 | 无动作 | 8 | 绕圈 |
| 1 | 前进指定距离 | 9 | 后退技能 |
| 2 | 后退指定距离 | 10 | 蛇形游走 |
| 3 | 左转指定角度 | 11 | 折线行进 |
| 4 | 右转指定角度 | 12 | 旋转 |
| 5 | 完全停止 | 13 | 脱困 |
| 6 | 前进技能 | 14 | 漫游 |
| 7 | 八字走位 | 15 | 摇摆 |

> `moveId=5`（完全停止）非常重要：它是唯一能可靠停止 AI 跟随模式的指令。`robot_stop_patrol` 停不了跟随（见 [排错文档](ebo-mcp-troubleshooting.md)）。

### `robot_stop_patrol`

立即停止正在进行的巡逻、巡航或导航任务。

无参数（除 `lang`）。

> 注意：本工具不能停止回充/回家过程（那要用 `robot_go_home` 的 `startUp=false`），也不能停止 AI 跟随模式（那要用 `robot_move` 的 `moveId=5`）。

### `robot_go_home`

让机器人回充电桩充电，或取消回充。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `startUp` | boolean | 否 | `true`（默认）= 开始回充；`false` = 停止/取消回充 |

## 三、跟随与搜索

### `robot_follow`

启动 AI 跟随，让机器人跟着人或宠物移动，或锁定目标保持在视野内。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `mode` | integer | 否 | `0`=跟随（一直跟着目标走），`1`=锁定（把目标保持在视野内） |
| `trackTarget` | integer | 否 | 跟踪对象：`4`=人（默认），`3`=宠物 |

> 停止跟随必须用 `robot_move` 的 `moveId=5`（完全停止），这是实测踩过的坑。

### `robot_search_360`

原地旋转 360 度搜索人或宠物。此调用会阻塞，直到机器人转完并报告检测结果（或短暂超时）。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `objId` | string | 否 | 搜索目标：`1`=人，`2`=猫，`3`=狗，`4`=通用宠物，或家庭成员 userId；空字符串表示只环视不指定目标 |
| `angleSpeed` | integer | 否 | 旋转速度：`1`=默认，`3`=更慢更精细 |

返回检测到的数量，以及是否找到指定目标。

## 四、语音与音乐

### `robot_speak`

让机器人用文字转语音（TTS）播报一段话。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `text` | string | 是 | 要播报的文字。保持简短自然，避免人称代词 |

内置 TTS 的支持语言列表包含丹麦语等语种，可用 BCP-47 标签（如 `da-DK`）指定。这里只做「文字 → 机器人自带音色」的合成，MCP 没有播放外部音频文件或自定义音色的接口——如果需要用自己生成的声音播报，得走设备本地的其他通道。

### `robot_set_volume`

调节音量：设为具体值、调大或调小。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `direction` | integer | 是 | `0`=设为精确值（需同时给 `volume`），`1`=调大一档，`2`=调小一档 |
| `volume` | integer | 否 | 目标音量 0–100，仅 `direction=0` 时有效 |

### `robot_play_music`

播放音乐。可以指定歌曲/歌手/专辑，也可以用场景描述播放（如"轻音乐""儿歌"）。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `song` | string | 否 | 歌曲名 |
| `singer` | string | 否 | 歌手名 |
| `album` | string | 否 | 专辑名 |
| `text` | string | 否 | 场景/风格描述，如"儿歌""轻音乐" |

### `robot_music_control`

控制正在播放的音乐（重播、暂停、恢复、停止、切歌）。要播放新音乐用 `robot_play_music`。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `controlType` | integer | 是 | `1`=重播，`2`=暂停，`3`=恢复，`4`=停止（清空队列），`5`=下一首，`6`=上一首 |

## 五、拍摄

### `robot_take_photo`

拍一张当前视角的照片。无参数（除 `lang`）。

### `robot_record_video`

录制一段视频。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `recordSeconds` | integer | 否 | 录制时长（秒），默认 10 |

## 六、调用约定

- 调用间隔：不要在短时间内高频连续调用工具，每次调用之间留出约 1 秒以上间隔（见 [排错文档](ebo-mcp-troubleshooting.md)）。
- 顺序执行：机器人不会为每一步动作返回"已完成"信号。要串联多个动作，需在每步之后调用 `robot_status` 轮询"设备任务"字段，确认上一步结束后再发下一步。
- 错误反馈：机器人目前没有运行错误的主动反馈，失败往往表现为"状态没变化"或"任务卡住"，需要通过状态查询和现场观察来定位。
